# 網路爬蟲從 0 到 1 · 互動教學

一份**給完全沒寫過爬蟲的人**的單頁互動教材，打開瀏覽器就能一路玩到會。

- 對話式講解：先想一想 → 打開答案 → 看程式 →「更深一點」
- 邊學邊玩：奶茶小舖、書蟲網路書店、閃購特賣會等互動模擬
- 從觀念到實戰：HTTP → HTML/CSS 選擇器 → requests → 分頁爬取 → 存檔 → 動態網頁
- 內建 **15 題結業測驗** 驗收學習成果
- 明暗雙主題，手機也能讀

| 1 | 🕷️ 歡迎來到爬蟲的世界 |

## 本地開啟

```bash
cd web-scraping-interactive-tutorial
python3 -m http.server 8080
# 瀏覽器打開 http://localhost:8080
```

也可以直接雙擊打開 `index.html`；整份教材是**單一自包含檔案**，不需要安裝任何東西。
